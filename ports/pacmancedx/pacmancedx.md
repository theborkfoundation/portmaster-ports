The Android build of the arcade remix, recompiled to run natively on Linux
handhelds. Its C++ engine and FMOD audio run directly on SDL2/KMSDRM or the
CFW's Mali fbdev backend — no Android runtime.

Boot, rendering, menu input, saves and audio work; gamepad input goes through
the CFW's controller mapping.

No game data is included — the loader reads the files you provide yourself.
