The Android build of the twin-stick roguelite, recompiled to run natively on
Linux/KMSDRM. Input, rendering, audio and save data work; developed and tested
in the kit's QEMU VM at 640×480.

The game settles at about 1.2 GB of RAM, so 1 GB handhelds run out of memory.

No game data is included — the loader reads the files you provide yourself.
